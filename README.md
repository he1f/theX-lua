# Набор Lua скриптов для работы с TRD и SCL файлами в Far Manager 3.0

## Что это?

В этот раз набор плагинов написал с нуля, но с помощью всё того же
ИИ, но куда сегодня без него.

# Как ставить?

Скопируйте все файлы в каталог %FARPROFILE%/Macros/scripts

# Функционал

В основном повторен функционал плагинов xTRD (но только для TRD файлов) и xSCL.
Плюс поддержан просмотр ассемблерных листингов xLook и basic файлов.

Из важного:
- порядок выбора файлов запоминается - можно реорганизовать SCL файл
- theX\types.lua - имеет чуть расширенный синтаксис, что позволило более корректно
  дёргать описания некоторых трекерных форматов и наконец-то определять tasm 4.12
- файлы и каталоги в TRD удаляются по честному, т.е. ставим 0x01 в первый символ,
  но в меню плагина есть метод MOVE
- пустые SCL и TRD файлы также можно создавать из меню плагинов

# Про xLook

Если необходимо, то можно настроить чтобы он открывал hobeta файлы на обычных
панелях. Для этого подойдут ассоциации:

Маска файлов: "*.![ab]"
Действие на нужную вам кнопку: xlook:!\!.!
