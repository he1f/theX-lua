# Набор Lua скриптов для работы с TRD и SCL файлами в Far Manager 3.0

## Что это?

На-vibe-кодил за несколько вечеров набор скриптов для работы TRD и SCL файлами
в ФАРе. У меня работает в последней сборке, но скорее всего должно завестись и
в более ранних.

# Как ставить?

Скопируйте все файлы в каталог %FARPROFILE%/Macros/scripts

# Функционал

В основном повторен функционал плагинов xTRD (но только для TRD файлов) и xSCL.
Плюс поддержан просмотр ассемблерных листингов xLook.

Из важного:
- порядок выбора файлов запоминается - можно реорганизовать SCL файл
- theX\types.lua - имеет чуть расширенный синтаксис, что позволило более корректно
  дёргать описания некоторых трекерных форматов и наконец-то определять tasm 4.12

# Что дальше?

плагина.
